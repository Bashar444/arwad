# Trademark policy

"Arwad" is the name of this programming language and project, owned by Bashar Al Agha. Registration as a trademark is in preparation ([ADR-0003](docs/adr/0003-mit-licence-dco-clean-room.md)). This policy applies to the name and to any official logo.

The code is MIT-licensed: you may use, modify and redistribute it freely. The *name* is different, because it tells users which software is the official one.

## Allowed without asking

- Referring to Arwad by name in articles, papers, talks, teaching material and comparisons.
- Stating that your software works with, or is built on, Arwad.
- Distributing unmodified official releases under the name.

## Requires permission

- Distributing a modified version under the name "Arwad". Forks must use a different name.
- Using the name or logo in a product, company or domain name, or in a way that suggests endorsement.

## Third-party names

"Goose" is the name of Wouter van Oortmerssen's programming language (and also of an unrelated open-source AI agent); "R" refers to the R language of the R Foundation and the R Core Team. Arwad uses those names only to describe what it builds on, and claims no affiliation with or endorsement by them.
