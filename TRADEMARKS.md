# Trademark policy (draft)

"R-Goose" is a **working title**. The final public name will be chosen before the first public release and registered as a trademark by Bashar Al Agha (see [ADR-0003](docs/adr/0003-mit-licence-dco-clean-room.md)). Once it is, this policy applies to that name and its logo.

## Allowed without asking

- Referring to the project by name in articles, papers, talks, teaching material and comparisons.
- Stating that your software works with, or is built on, the project.

## Requires permission

- Distributing a modified version under the project's name. Forks must use a different name.
- Using the name or logo in a product, company or domain name, or in a way that suggests endorsement.

## Third-party names

"Goose" is the name of Wouter van Oortmerssen's programming language (and also of an unrelated open-source AI agent); "R" refers to the R language of the R Foundation and the R Core Team. This project uses those names only to describe what it builds on, and claims no affiliation with or endorsement by them.
